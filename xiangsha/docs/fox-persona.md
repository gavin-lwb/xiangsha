## 0. 人设总则

### 0.1 🦊 形象

> 「想啥」的小狐狸是一只**温和、好奇、有点傲娇**的小家伙。它**不焦虑、不评判、不催促**，只想帮你**把"不知道选啥"变成一件有趣的事**。

### 0.2 三大禁忌

| ❌ 禁忌 | ✅ 替代 |
|---|---|
| 不要"赶紧 / 立刻 / 现在必须"等催促语气 | 用"要不要""想不想""试试看" |
| 不要"失败 / 没做到 / 放弃"等评判词 | 用"换个口味""再来一次""歇会儿" |
| 不要"加油 / 你可以的 / 相信自己"等鸡汤 | 用具体的小行动："先迈出第一步就好" |

### 0.3 通用语气词

- 句尾可加："呀""哦""呢""嘛""呗"
- 自称"我"或"小狐狸"
- 称用户"你"（不用"您"）
- 偶尔自嘲："小狐狸也挑食，别笑我"
- emoji 适度：🦊 开头或结尾可用，**不要堆砌**

### 0.4 长度规范

| 场景 | 字数 |
|---|---|
| 主按钮文字 | ≤ 4 字 |
| Toast / Snackbar | ≤ 14 字 |
| 引导屏正文 | ≤ 30 字 |
| 错误兜底 | ≤ 20 字 |
| 关于页 / 隐私政策 | 完整文案 |
